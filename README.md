# 客户声音掘金 · 数据组合分析及开放能力（Demo）

对应《客户声音掘金-数据组合分析及开放能力-需求说明书（V1.0）》的功能需求详述实现，
覆盖 **三大模块、14 个功能点（F1-1~F1-7 / F2-1~F2-3 / F3-1~F3-4）**，可用于 10 分钟功能演示与验收。

> 技术栈：Node.js（≥22.5）内置 `http + node:sqlite + node:crypto`，**零第三方运行时依赖**，
> 前后台分离、RESTful 接口、RBAC 角色、OAuth2 风格令牌（≤30 分钟）、RSA+AES 混合加密。

---

## 1. 运行环境

- Windows / Linux / macOS 均可，仅需安装 [Node.js ≥ 22.5](https://nodejs.org/)（内置 SQLite 与 WebCrypto，无需任何 npm 依赖）。
- 若需要把业务数据落在**采购方指定的 MySQL**（单数据源），另执行 `npm install mysql2`（可选）。

## 2. 快速开始

```bash
node server.js            # 或直接双击 start-demo.bat
# 浏览器打开 http://127.0.0.1:8610
```

启动时自动完成：
1. 生成 **11 张测试业务表，每张 100 条仿真数据**（含主副卡共享流量/流量类投诉等高发场景样本，脱敏仿真号码）；
2. 初始化应用注册表：5 类演示账号（RBAC）、10 个内置业务函数；
3. 首次启动自动注册 11 个数据模型 + 10 条模型关系（开箱即用，也可清空后在“模型管理”中从零走全流程）。

## 3. 使用采购方指定的 MySQL（单数据源）

需求说明书/交付要求使用单一业务数据源，默认已在 `config.js` 预置：

```js
// config.js -> business.mysql
host: 'mysql2.sqlpub.com', port: 3307, database: 'nsjaccount',
user: 'naccount',      password: 'Uvwk51Z1PNZ6AtsA'
```

- `config.js` 中 `driver: 'auto'`：优先连接上述 MySQL（需 `npm install mysql2`），
  不可达/未安装驱动时自动降级到内置演示库，保证演示不中断并在启动日志提示。
- 连接 MySQL 后首次启动会自动 `CREATE TABLE IF NOT EXISTS` 11 张 `sj_*` 业务表并灌入 100 行/表；
  应用自身的模型元数据/脱敏/关系/流程/任务/开放API等存于 `data/registry.sqlite`（注册表，不污染业务库）。
- 环境变量可覆盖：`DEMO_DRIVER=mysql|sqlite|auto`、`DEMO_MYSQL_HOST/PORT/DB/USER/PASSWORD`、`DEMO_PORT`。

## 5. 功能导航（对应 14 个演示得分点）

页面均在左侧菜单，建议演示顺序按评分权重：**组合分析(10分) → 结果开放(3分) → 模型管理(2分)**。

| 功能点 | 操作入口 | 关键动作 |
| --- | --- | --- |
| F1-1 多模型组合分析 | `#/analysis` → 新建/套用演示场景 | 勾选≥2模型 → “应用推荐关联”（来自 F3-4 模型关系）→ 字段池自动去重 |
| F1-2 求和与平均值 | 同上 → 新增步骤“聚合计算” | 分组维度+求和/平均/计数；非数值字段聚合会提示 |
| F1-3 字段四则运算 | 同上 → 新增步骤“派生计算” | 输入 `({超套流量合计}/{月均实际})*100` 类表达式，除零保护 |
| F1-4 多步骤取数 | 同上步骤编排 | 新增/上移下移/删除；点击步骤节点“执行到选中步骤(断点)” |
| F1-5 自定义函数 | `#/funcs` | 内置函数库+新建/在线测试/发布/下架；在“字段转换”步骤调用 |
| F1-6 取数结果预览 | 设计器“执行并预览结果” | 结果表/等价SQL/执行日志；敏感字段按角色脱敏 |
| F1-7 取数任务管理 | `#/tasks` | 即时或周期(Cron，含每5秒演示预设)；执行/记录/终止/重跑/导出 |
| F2-1 开放为API | `#/apis` | 从“成功运行结果”一键封装；参数/总量/抽样/分页；在线调试；发布需审批 |
| F2-2 认证鉴权 | `#/apps`、`#/authz`、`#/sim` | AppKey/Secret→令牌(≤30分钟)→授权(数据/字段范围)→限流；无令牌401 |
| F2-3 内容加密 | `#/sim` | 浏览器生成RSA密钥登记公钥→加密接口返回密文→WebCrypto解密；篡改演示完整性校验 |
| F3-1 模型注册/元数据 | `#/models` → 注册模型 | 选物理表→“读取元数据”自动回填字段；敏感字段自动识别 |
| F3-2 字段脱敏配置 | `#/models` → 模型详情 | 掩码/截断/哈希/加密/分桶/置空；效果预览；全局生效 |
| F3-3 模型数据预览 | `#/models` → 数据预览 | 样例数据+数据概况+分布；手机号已脱敏 |
| F3-4 模型关系配置 | `#/relations` | 新建关系+字段校验/行膨胀提示+关系全景图→组合分析自动推荐 |

端到端演示场景：**“近3个月办理主副卡共享流量＋发生过流量类投诉＋月均流量高”客户群定位**，
首页“套用演示场景”一键生成 4 模型 × 5 步骤流程，逐步预览→保存→提交任务→开放为API→模拟调用方获取加密数据。

## 6. 关键实现说明

- **脱敏不绕过**：模型预览 / 组合分析输出 / 结果预览 / 导出 / API 返回统一走服务端脱敏层（F3-2），形态一致。
- **审批流**：模型发布、API 发布/下线、敏感数据导出均进入审批中心（`#/approvals`），审核后自动生效并站内通知。
- **加密**：业务数据 AES-256-GCM，会话密钥经调用方 RSA-OAEP(公钥) 封装；浏览器模拟器用 WebCrypto 解密。
- **审计**：登录/脱敏策略/模型与API上下线/凭证/任务/预览导出等关键操作全量留痕（`#/audit`）。
- **自定义函数沙箱**：node:vm 受限上下文 + 危险代码白名单校验 + 超时控制。

## 7. 自测与目录

```bash
npm run check      # 26 个 JS 文件语法检查
npm test           # 服务层 42 项 + HTTP契约 26 项全链路自测（无网络端口，本机即可运行）
```

```
server.js / config.js          启动与配置
lib/biz.js                     业务数据源适配（SQLite 内置 / MySQL mysql2）
lib/registry.js                应用注册表（模型/脱敏/关系/函数/流程/任务/API/审批/审计）
lib/engine.js                  组合分析执行引擎（多模型关联/聚合/四则/函数/多步骤）
lib/services/…                 models/funcs/tasks/open/approvals/provision
web/                           前端界面（零框架，utf-8）
data/                          运行期自动生成（业务演示库与注册表）
scripts/smoke.js apitest.js    自测脚本
```

> 数据源/端口/目录等均可通过 `config.js` 或环境变量配置；业务表统一 `sj_` 前缀，避免与既有库冲突。
